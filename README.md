# PSA Workshop

Независимый справочный интерфейс для работы с автомобилями Peugeot, Citroën и DS Automobiles.

## Возможности текущей версии

- Адаптивный интерфейс для компьютера и телефона.
- Навигация по разделам.
- Проверка формата VIN (не является расшифровкой VIN).
- Ручной выбор автомобиля.
- Разделы электросхем, запчастей и технической информации.
- Список внешних справочных источников.

## Публикация на GitHub Pages

1. Откройте Settings репозитория.
2. Перейдите в Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку main и папку /(root).
5. Сохраните настройки и дождитесь публикации.

## Важно

В текущей версии нет подключённой базы VIN, заводских электросхем или каталога OEM-запчастей. Интерфейс не генерирует технические данные и не подменяет заводскую документацию. Для подключения источников необходимы проверяемые данные, разрешённый доступ и, если требуется, API-ключи. Не публикуйте секретные ключи в клиентском коде GitHub Pages.

## Стек

Чистые HTML, CSS и JavaScript. Сборка и сервер не требуются.

## Дисклеймер

Проект не связан с Peugeot, Citroën, DS Automobiles или Stellantis и не является официальным продуктом этих компаний.
